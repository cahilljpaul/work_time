# Ideas for next

The clock wheel is the main focus of the app. These build on it.

## Free time / general calendar
- Weekly free-time totals
- Recurring "protected" time (gym, family) that always blocks the wheel
- Tags for tasks, with a per-week target (e.g. 3h of project time)
- Real collaboration: shared task lists and seeing when others are free (needs accounts / iCloud sharing). Simple sharing (task invite, free-gap text) is already built

## Data and phone
- Export / import backup (data currently lives only in the browser's local storage)
- Install as a home-screen app (PWA) so it works offline and iOS keeps the data
- Host it (GitHub Pages / Netlify) rather than opening the file directly

## Time bank and week
- Manual bank adjustments and a per-week bank history
- Copy a day to other days, or repeat last week
- Day-type presets (WFH, Office, Alternative office)
- Flexi limits: warn on max bank balance or earliest start / latest finish

## Wheel
- Reminders for lunch and finish time
- Configurable look-ahead (30 min / 1h) and half-hour notches
- Setting for personal sleep goal (currently a fixed 7h check)

## Personal / projects
- Recurring tasks, carry-over of unfinished tasks, priorities / categories
- Calendar export (.ics) including work hours and free-time bookings
